# 🤖 Data Classification Using AI

A simple **supervised machine learning classification project built with Python** that uses the **Iris dataset** to classify flowers into three different species using the **K-Nearest Neighbors (KNN)** algorithm.

This project was created as part of my internship to practice Python programming, dataset handling, data preprocessing, supervised learning, model training, prediction, model evaluation, and automated testing.

## ✨ Features

* 🌸 Uses the Iris dataset for classification
* 📊 Uses four flower measurement features
* 🔀 Splits the dataset into training and testing sets
* 📏 Standardizes features using `StandardScaler`
* 🤖 Implements the K-Nearest Neighbors (KNN) algorithm
* 🎯 Uses K = 5 for classification
* 🔮 Predicts flower species using the trained model
* 📈 Calculates accuracy, precision, recall, and F1 score
* 🧩 Generates a confusion matrix
* 🖼️ Automatically saves the confusion matrix as an image
* 📝 Automatically saves model evaluation metrics
* 🧪 Includes automated tests using Pytest
* 🔄 Uses a fixed random state for reproducible results
* 📂 Uses a modular project structure

🧠 How It Works

The project uses a supervised learning approach to classify Iris flowers into their respective species.

The machine learning pipeline consists of the following steps:

Iris Dataset
     ↓
Load Dataset
     ↓
Separate Features and Labels
     ↓
Train-Test Split
     ↓
Feature Scaling
     ↓
KNN Model
     ↓
Model Training
     ↓
Prediction
     ↓
Model Evaluation
Dataset Loading

The Iris dataset is loaded using Scikit-learn.

The dataset contains:

150 samples
4 features
3 classes

The four features are:

Sepal Length
Sepal Width
Petal Length
Petal Width

The three classes are:

Setosa
Versicolor
Virginica
Train-Test Split

The dataset is divided into:

80% → Training Data
20% → Testing Data

The training data is used to train the KNN model, while the testing data is used to evaluate the model on unseen samples.

Feature Scaling

The features are standardized using StandardScaler.

The scaler is fitted on the training data and then used to transform both the training and testing data.

KNN Classification

The project uses the K-Nearest Neighbors (KNN) algorithm.

The model uses:

K = 5

KNN classifies a new sample by examining its nearest neighboring training samples and determining the class based on those neighbors.

Model Evaluation

After generating predictions, the model is evaluated using:

Accuracy
Precision
Recall
F1 Score
Confusion Matrix
